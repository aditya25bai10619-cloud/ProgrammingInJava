Problem statement:Answer evaluation in bulk has many flaws associated with it. It is possible that different humans have different perspectives and criteria in judging a student’s answer which causes unfairness in evaluation. There could also be a case when evaluation becomes repetitive and tedious when answer needs to be evaluated with reference to a bench mark.
Scope of the project: The project tries to solve the problem of repetitive evaluation of answers to questions with respect to a reference answer, it also solves the problem of evaluation criteria of different humans and makes the evaluation fair for everyone.
Target users: Teachers and evaluators.
High-level features: Incorporates llm api and is easy to read in high-level language.
